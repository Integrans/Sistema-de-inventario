Objetivos específicos:
● Registrar productos con sus atributos (nombre, cantidad, precio)
● Controlar entradas y salidas de inventario
● Mostrar el stock actualizado en tiempo real
● Generar alertas cuando el stock sea bajo
● Consultar historial de movimientos
Requerimientos funcionales:
● Entradas/salidas
● Alertas de bajo stock
Requerimientos no funcionales:
● Precisión de datos
● Auditoría básica
